## Import

Не рекомендуется делать классы вне пакета (в корне проекта)
```java
//compilation unit
[package]
[import]
[class A{}]
```

```java
package my;

class A{
	полно.квалифицированное.имя.B b;
	A(полно.квалифицированное.имя.B b) {
		...
	}
}
```

вместо этого можно использовать короткую запись используя `import`

```java
package my;
import полно.квалифицированное.имя.B;
import java.util.List

class A{
	List lst;
	B b;
	A(B b) {
		...
	}
}
```

==🔴**нельзя импортировать 2 одинаковых класса**==
например:
```java
import полно.квалифицированное.имя.B;
import ru.ermakov.B B;
```

можно делать псевдонимы, но при компиляции они заменяться на просто имена
```java
import ru.ermakov.B B as BB;
```

```java
import static my.A.URL
...
sout(URL) // - поле из класса my.A
```

Импорт всего:
```java
import my.*
import edu.* // здесь не будет ошибки (замедление компиляции)

class Main {
	psvm() {
		A a1 = new A();
		AA a2 = new AA(); // - ошибка здесь
	}
}
```

Обычно полный импорт не рекомендуется, если не используются все классы из пакета

**==🟢Class clz = Class.forName(url);==

Звездочка это **только класс**

==🔴Нельзя какую-то часть пакета обернуть в звездочку а потом по остальной части имени обратиться к классу==

## Пакеты влияют на инкапсуляцию

По умолчанию модификатор доступа - *internal* a.k.a *package-private* (внутри одного пакета)
У интерфейсов по умолчанию - *public*

```java
class A {
	int x; // доступно всем внутри пакета
	public int y; // вообще всем
	private int z; // только внутри класса
}
```

private-package нужен, чтобы защитить пользователя, который будет пользоваться нашим классом внутри **своего** пакета, а разработчики могут общаться между собой и не писать модификатор, чтобы обращаться к полям и методам

## Protected

 Доступ: только внутри класса **и его наследников**

```java
public class A {
	int x;
	public int y;
	private int z;
}
```

```java
import my.*

class Main {
	psvm() {
		B a1 = new B();
		sout(a1.a); - нельзя (Main не наследник, а мы все еще к полю обращаемся)
	}
}

class B extends A {
	int getA() { return a; }
}
```


private и protected применяются только к членам класса (включая классы внутри класса)

---
```java
class Main {
	psvm() {
		A a = new A();
		A.B ab = a.new B();
		A.B.B abb = ab.new B();
		A a2 = ab;
	}
}
```
