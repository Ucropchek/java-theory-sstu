# Межсессионная аттестация: `@DefaultValue`

Второй семестр второго курса. Вариант 1.

## Условие

Разработайте аннотацию `@DefaultValue` для параметров методов. Если при вызове метода аргумент, соответствующий помеченному параметру, равен `null`, подставьте значение, указанное в аннотации. Механизм должен работать для всех бинов Spring.

Ниже приведены примеры ожидаемого поведения, не дополнительные требования:

- При вызове с `null` для помеченного параметра в метод передаётся значение из аннотации.
- При вызове с ненулевым аргументом для того же параметра исходный аргумент не меняется.
- Аргумент `null` для параметра без аннотации остаётся `null`.
