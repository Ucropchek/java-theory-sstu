Идея генерика в том, что тип переменной сам становится переменным

```java
class Basket<F> {
	private F pie;
	
	F get() {
		Pie tmp = pie;
		pie = null;
		return tmp;
	}
	
	void put(F pie) {
		this.pie = pie;
	} 
	
	boolean isEmpty() {
		return pie == null;
	}
}
```

---
                                                            
F - **типовая переменная** (некая переменная принимающая какой-то тип данных)
Класс с типовой переменной называется **генериком**
Ссылка на основе класса - параметризованный тип
В данном случае Pie - **параметризация**
                                                            
---

*Что генерики убогие вызвано поздним появлением в языке*

Граница стирания типа
Нельзя присваивать типу не себя или младших типов

~~`List<String> = new ArrayList<Basket>`~~

Имена переменных в сигнатуре генерика именуем СТРОГО одной буквой, чтобы не было неоднозначности с названием передаваемого класса

**==🟡& Cloneable & Closeable==** -  наследует интерфейсы Cloneable и Closeable

**Типовые пересечения**
```java
class Basket<F extends Food & Cloneable & Closeable> {
	...
}
```

Поля входящего типа должны быть как граница стираемого типа

```java
class Basket<F extends Food> {
	Food pie;
	...
}
```
```java
class Basket<F> {
	Object pie;
	...
}
```

extends - маска границы сверху
super - маска границы снизу

```java
class Basket<? extends Food> {
	Food pie;
	...
}
```
```java
class Basket<? super Food> {
	Food pie;
	...
}
```
можно сделать
```java
class Basket<?> {
	Object pie;
	...
}
```

Это полезно, когда непонятно какой класс именно будет использоваться

```java
Basket<Food> basket = new Basket<>();
Basket<?> basket1 = basket;
Basket<Apple> basket2 = basket1; // ошибка
или
Basket<Apple> basket2 = (Basket<Apple>) basket1; // предупреждеение
```


| тип ссылки          | List   | List<`A>    | List<\?>        | List<\? extends> | List<\? super>   |
| ------------------- | ------ | ----------- | --------------- | ---------------- | ---------------- |
| можно ли присвоить  | any    | List<`A>    | any             | A & extends A    | A и его родители |
| его можно присвоить | any    | any         | только с кастом | any              | any              |
| get                 | Object | A           | Object          | A                | Object           |
| put                 | __     | A и потомки | __              | __               | A и потомки      |
В маски типа (?) можно путать null, хотя это бесполезно по сути
