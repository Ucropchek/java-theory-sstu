Суть в том, чтобы предоставить пользователю **безопасный** объект

Инкапсуляция

| Инкапсуляция | Тип                                                                    |
| ------------ | ---------------------------------------------------------------------- |
| состояния    | объект в любой момент времени находится в безопасном состоянии объекта |
| реализации   |                                                                        |
| поведения    | код у которого есть                                                    |
Инкапсуляция - не защита от злоумышленника, а защита от случайных глупых действий.

```java
public void setGrade() {
	if (x >= 2 && x <= 5) {
		grades.add(x);
	}
}
```

Ключевое слово private
запрещает залезать в поле или метод из вне
Чаще всего поля приватятся, потому что это внутрянка.
Внутренние методы приватим, чтобы не ломалось и было эффективно

**Интерфейс объекта** - список всех публичных методов

Есть заранее созданные объекты и вместо конструкторов можно использовать методы инициализации
