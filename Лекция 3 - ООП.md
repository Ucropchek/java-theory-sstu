# Парадигмы

Парадигмы делятся на императивные и декларативные
Императивная - как достигнуть цели?
- процедурное (набор шагов, чтобы что-то сделать) 1934 г.
- ООП 1970-1980-ые гг. когда появились оконные интерфейсы
Декларативное - какой результат я хочу получить (что я имею в виду)?
- логическое
- функциональное 1934 г.

```C
//Процедурное
// СТЭК
struct Stack{
	int[] arr = new int[100];
	int size = 0;
}

void push(Stack s, int x) {
	s[s.size++] = x;
}

int pop(Stack s) {
	return s[--s.size];
}

void main() {
	Stack s1 = new Stack();
	Stack s2 = new Stack();
	push(s1, 3);
	push(s1, 6);
	push(s2, 2);
	sout(pop(s2, size)) //2
	sout(pop(s1, size)) //6
	sout(pop(s1, size)) //3
}
```
