## Структурные

Шаблоны: 
- Декораты
- Адаптеры
- Прокси

И в декораторе и в адаптере ссылка отличается

Ссылка неотличима от оригинала и добавляешь новое поведение - прокси
Ссылка обертки отличается от оригинала, но поведение такое же - адаптер
Ссылка обертки отличается от оригинала, и поведение отличается - декоратор


Фасад/Композит

Группа групп групп групп - композит


## Поведенческие

Команда - список действий с внешним управлением 
```java
class B {}
class A {
	List<B> b;
	// цепочка ответственности
	void m(int x) {
		if (x == 0) return;
		next.m(x);
	}
}
```

Нужно сказать, что у каждого объекта есть следующий объект

Либо ты хранишь одно действие, либо связный список действий, либо машину состояний (граф действий)

### Шаблонный метод (это название единственного паттерна реализованного на наследовании)
```java
abstract class Original {
	public final void main() {
		step1();
		step2();
		step3();
	}
	
	protected abstract void step1();
	protected abstract void step2();
	protected abstract void step3();
}
```
