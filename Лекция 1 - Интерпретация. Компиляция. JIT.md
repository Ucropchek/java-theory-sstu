### Как исполняется приложение

ИНТЕРПРЕТАЦИЯ

JIT      (just in time)       (во время исполнения)   ___ компиляция
AOT   (ahead of time)   (до исполнения)              ________ / 

```java
class Start() {
	psvm() {
		A.fun()      //NoClassDefFoundError если нет класса о чем мы узнаем в момент исполнения приложения
	}
}
```

JIT-компиляция берет часто повторяющиеся участки кода в машинный и компилирует прямо во время исполнения
Сначала медленно исполняется, останавливается на промежуточную компиляцию, продолжает и разгоняется потихоньку, вставляя уже скомпилированные участки кода
![[Pasted image 20260907110437.png]]
Кусок JDK отвечает за **JIT-компиляцию**
Каждый раз может быть **разное время исполнения**, поэтому сравнивать некорректно
Надо запустить машину, **прогреть ее** и **после** проверочной нагрузки запустить тест
==**Скорость зависит от правильного прогрева**==

**AOT-компиляция** нужна, когда запросы должны выполняться за гарантированное время (realtime)

Задачи миллиардных вычислений идеальна под C++,
А малое кол-во вычислений, но большое кол-во действий идеально под Java
Они взаимно обгоняют друг друга в своих сферах
